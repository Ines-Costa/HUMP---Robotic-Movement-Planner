An improved robotic movement planner developed at the University of Minho by Gianpaolo Gulletta. His work can be found at https://github.com/zohannn.

This project includes motion generation for RAMBO (Robotic Anthropomorphic Manipulator for Bimanual Operations) [1], a robotic platform developed at the University of Minho, designed to perform bimanual manipulation tasks for shelf replenishment.

<img width="398" height="446" alt="image" src="https://github.com/user-attachments/assets/39d1b4d1-f6c8-46b4-9b8e-806620c03eb7" />

The system combines conventional robotic grippers with more anthropomorphic robotic hands, such as the qb SoftHand 2, with the goal of enabling more human-like manipulation and, in the future, supporting Human-Robot Collaboration (HRC).
